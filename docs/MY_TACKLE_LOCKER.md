# My Tackle Locker

Angler Intel v6.13 turns the old rig guide page into a personal tackle locker plus owned-gear trip planning.

What is in scope:
- rods, reels, line, lures, terminal tackle
- manual entry first
- edit, favorite, archive, retire, delete
- JSON-backed storage in `data/gear_inventory.json`
- recommended setup, packing list, usage, and maintenance summaries
- catch-linked gear references and gear service tracking
- generic fishing rig reference preserved at the bottom of the page

What is not in scope yet:
- SQLite authority migration
- full relational gear analytics
- automatic unreviewed imports

The goal is to make the app understand the gear the user actually owns before the relational V7 work begins.
