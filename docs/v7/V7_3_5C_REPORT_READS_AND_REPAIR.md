# V7.3.5c SQLite Report Reads and Artifact Repair

SQLite reports with a complete saved snapshot can be listed and opened through
the staged-read setting. Their JSON snapshot, report index entry, and printable
HTML can be regenerated by `tools/v7_3_5_repair_report_artifacts.py` with an
explicit `--confirm`.

Legacy reports that predate complete snapshot storage remain readable through a
temporary, visibly recorded JSON fallback in `sqlite_with_json_fallback` mode.
Strict SQLite read mode does not silently fall back. App Health shows the most
recent report fallback and artifact-repair event.

Reports remain JSON-authoritative until V7.3.5e. This task adds no authority
transition and does not alter default production read selection.
